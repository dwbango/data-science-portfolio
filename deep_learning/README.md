# Deep Learning Projects

This folder contains deep learning projects using neural networks for image classification and time series forecasting.

## Projects

### CNN MNIST Digit Classification

Uses the MNIST handwritten digit dataset to classify digits with a Convolutional Neural Network. The project includes image preprocessing, model training, validation, and evaluation using classification metrics.

File: `cnn_mnist.ipynb`

### RNN AAPL Stock Forecasting

Uses historical Apple stock data to build a recurrent neural network model for time series forecasting. The project includes sequence creation, model training, and evaluation using forecasting error metrics.

File: `RNN_APPL_Stock.ipynb`
