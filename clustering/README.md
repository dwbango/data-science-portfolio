# Clustering Projects

This folder contains unsupervised machine learning projects focused on grouping similar observations and exploring patterns in data.

## Projects

### K-Means Clustering: Obesity and Lifestyle Data

Uses an obesity and lifestyle dataset to identify groups of individuals with similar health, lifestyle, and physical characteristics. The project includes data preprocessing, feature scaling, k-means clustering, cluster validation, and visualization.

File: `kmeans_clustering_obesity.ipynb`

## Tools Used

- Python
- pandas
- NumPy
- scikit-learn
- matplotlib
- Jupyter Notebook
