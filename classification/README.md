# Classification Projects

This folder contains supervised machine learning projects focused on classification tasks. These projects use Python and common data science libraries to clean data, train models, and evaluate predictive performance.

## Projects

### Adult Income KNN Classification

Uses the Adult Income dataset to predict whether an individual earns more than $50K per year. The project includes data preprocessing, categorical encoding, feature scaling, k-Nearest Neighbors modeling, and evaluation.

File: `adult_income_knn.ipynb`

### Naive Bayes Airline Sentiment Analysis

Uses the Twitter US Airline Sentiment dataset to classify airline-related tweets by sentiment. The project includes text preprocessing, TF-IDF vectorization, Naive Bayes modeling, and model evaluation.

File: `NB_NLP_Airline_Sentiment.ipynb`

### SVM MNIST Digit Classification

Uses the MNIST handwritten digit dataset to classify handwritten digits using a Support Vector Machine model. The project includes preprocessing, model training, and evaluation using accuracy, confusion matrix, and classification metrics.

File: `svm_mnist.ipynb`
